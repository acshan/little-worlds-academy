# 微光游戏工坊 · 给游戏开发新手的互动教程

这是一门中文、本地优先的互动课：**18 课、5 个阶段、可执行的 JavaScript 练习、实时二维/三维实验，以及一款可独立运行的结业游戏**。

从变量与坐标开始，学会用 Three.js 做三维场景与像素精灵，再加入敌人、自动攻击、命中、经验、升级、进化、关卡、暂停、存档、性能和发布。使用原创角色，学习类似 PokéBonk 的技术与设计思路。

## 在线学习

[打开微光游戏工坊](https://acshan.github.io/little-worlds-academy/) · [试玩结业游戏](https://acshan.github.io/little-worlds-academy/project/)

## 打开教程

在仓库根目录运行：

```sh
npm run learn
```

或进入本目录：

```sh
node server.mjs
```

在浏览器访问 **http://127.0.0.1:4180/**。需要 Node.js 22+，但首次运行不必再安装 npm 包，Three.js 固定版本的本地模块已经随项目提供。

## 发布到 GitHub

可直接使用 GitHub Pages，详见 [部署说明](DEPLOY-GITHUB.md)。在线站点无需 Node.js；学习记录保存在各自浏览器，可导出后迁移。

## 怎么学

每课有四个页签：

1. **理解**：用具体例子解释问题、单位、数据和规则。
2. **动手**：编辑真实 JavaScript 并运行；结果会改变右侧实验；挑战有明确的结果检查。可以看提示、参考答案和完整项目源文件。
3. **检验**：一道概念判断题，提供反馈。代码任务和小测都通过后才能点亮这一课。
4. **笔记**：用自己的话记录理解与疑问。

右侧实验可调参数。三维实验先点“开始实验”，再点画布取得键盘焦点；WASD/方向键移动，攻击自动进行。触屏有方向键。切到后台会暂停。源代码实验在独立 Worker 中运行，不能访问页面 DOM/本地存储，也禁止网络请求；超过 1.2 秒会终止本次执行。

你可以自由跳课，不设置强制解锁。建议按顺序，每次学 1–2 课，做完独立练习再进入下一步。10–16 小时只是阅读加练习的参考，不是完成速度要求，也不保证学完就具备商业游戏全部制作能力。

## 学习路线

| 阶段 | 课程 | 阶段成果 |
|---|---|---|
| 出发之前 | 目标、JavaScript、工作台 | 能读代码、知道文件怎么运行 |
| 让世界动起来 | 游戏循环、方向输入 | 正确处理时间与移动 |
| 走进三维森林 | Three.js、像素精灵 | 知道混合二维/三维画面怎么实现 |
| 做出游戏的乐趣 | 敌人、射击、碰撞、升级、进化、关卡 | 一局可以玩和结束的幸存者游戏 |
| 完成并交付 | 状态机、存档、性能、反馈、发布 | 能修改、验证和独立运行自己的作品 |

## 验证

```sh
node tests.mjs
```

检查全部参考答案、题目、源码链接、JavaScript 语法，以及移动、暂停、扫掠碰撞、伤害间隔、升级、防重复进化、重开重置、精英时间轴与胜负规则。测试包含完整默认关卡的纯模拟通过，但这不代替真实玩家、GPU、触屏和长时内存测试。

浏览器走查记录见 `browser-qa.json`，包含 18 课导航、代码执行与超时、进度/笔记保存、真实三维参数变化、短关卡胜利与 390 像素窄屏布局；未声称已做真实手机硬件或完整性能基准测试。

重新生成文字备份和下载包：`node package.mjs`（打包还需要 Python 3；日常阅读和游玩不需要）。Three.js 原 MIT 许可证保留在 project/vendor/LICENSE。本课程不是 Three.js 官方课程，技术参考入口列在界面“官方资料”中。
