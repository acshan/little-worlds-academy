# 我的第一颗像素 · 起步模板

安装 Node.js 22+，在解压后的文件夹中打开终端，运行：

```sh
npm run dev
```

访问 `http://127.0.0.1:4181/`。不用安装其他 npm 依赖，也不要直接双击 HTML。

`main.js` 中有三个 TODO：记录按键、计算 dt、按秒更新角色的位置。先完成 D/A 左右移动，再自己加入 W/S 与斜向归一化。保存后刷新浏览器。

如果你已经启动了完整结业游戏，它也默认使用 4181 端口。先在旧服务器的终端按 **Ctrl+C** 停止它，再启动这个模板；反过来也一样。不要把打开旧服务器的页面误认为新文件没有生效。

起步模板是二维 canvas，速度单位为像素/秒；完整 3D 项目用世界单位/秒。从这里到完整游戏的分步路线见课程的 `BUILD-YOUR-OWN.md`。
