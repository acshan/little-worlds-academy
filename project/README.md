# 微光守林人 · 你的第一款 3D 游戏

这是“微光游戏工坊”互动课程的原创结业项目。它使用 **Three.js 0.186.0**，以真正的三维场地配合代码绘制的二维像素角色。目标是提供一个容易理解和修改的教学基础，不是复刻完整 PokéBonk。

## 运行

安装 Node.js 22 或更高版本。解压后，在这个文件夹里打开终端：

```sh
npm run dev
```

打开终端显示的 **http://127.0.0.1:4181/**。无需 `npm install`：固定版本的官方 Three.js 模块已附带在 `vendor/`，可以离线运行。不要双击 HTML；ES 模块需要通过本地 HTTP 服务器打开。

WASD / 方向键移动，自动攻击。收集青色晶体升级。Esc 或右上角按钮暂停。触屏提供方向键。活到 90 秒胜利，60 秒出现一个精英；不要求击败精英才算赢。画布必须先点击取得键盘焦点。

## 每一帧发生什么

`Game.tick` 读取输入 → `World.update` 计算规则 → `View.sync` 同步并渲染 → 每约 100ms 更新一次 HUD。`World` 不导入 Three.js，也不知道 DOM 是什么。你能在 Node 中单独测试它。

`phase` 可能是 ready / play / paused / upgrade / over / won。只有 play 推进模拟；升级时读卡片不计时。切换浏览器标签页会暂停，回来后点继续。终局用 `settled` 保证本局纪录只累计一次。

## 动手改三次

1. **改节奏**：`config.js` 中 duration 改为 45，bossAt 改为 30，分别试 damage=1 和 damage=2。每次只改一项，观察能否通关。
2. **改主角**：`art.js` 的 seedling 中，`.` 是透明，`b` 是身体，`g` 是叶子。画一个同为 16×16 的原创形象。刷新后观察边缘与锚点。
3. **新增升级**：`state.js` 的 chooseUpgrade 增加 `stride` 分支，将 speed 乘 1.1；`main.js` 升级选项 HTML 加一个 `data-upgrade="stride"` 按钮。验证每次只加 10%，不是每帧都加。

然后试试：把固定三个升级改为从五个选项里随机抽三个。先写规则，再补界面，最后验证不会出现重复选项。

## 调试顺序

- 黑屏：检查 Console 的第一个报错。Standard 材质需要灯光；相机要朝向地面；浏览器需支持 WebGL 2。
- 键盘没反应：先点画布。检查输入方向是否为零、phase 是否还是 play。
- 攻击没伤害：检查弹丸 damage、敌人 hp、碰撞半径。不要把视觉透明边缘当作精确碰撞体。
- 新参数不生效：保存文件并刷新。已有弹丸保留发射时的伤害；完整刷新会创建新的默认配置。
- 重复升级或结算：检查 evolved / settled 等一次性标志；事件与持续条件不是同一回事。

## 测试

```sh
npm test
```

测试覆盖核心规则，不包含真实 GPU、手机硬件或所有构筑。浏览器中还应实测暂停、升级、失败、胜利、重开、屏幕尺寸变化与音频开关。

## 已有边界

- 本地单人游戏，没有服务器账号、云存档、排行榜与反作弊。
- 本地只保存历史最佳击败数和局数，不保存进行中的对局。清除站点数据会丢失本地纪录。
- 敌人直接追踪，不做复杂寻路；场景没有可互动的高低地形。
- 树木、石头和草叶是装饰，没有碰撞；可作为你下一次独立迭代的练习。
- 几十个敌人的教学规模，角色逐 Sprite 渲染；不是完整精灵批处理引擎。
- 短音默认关闭。减少闪动默认开启，但不是关闭全部动画。
- 几何、角色图案与教学逻辑为本课程原创；Three.js 的许可证见 vendor/LICENSE。

## 发布

它是静态网站。把本文件夹中的 index.html、style.css、src/、vendor/ 放到支持静态文件的 HTTPS 托管服务即可；server.mjs 只用于本机开发，不需要上传运行。不要遗漏相对路径中的子文件夹。发布后重新走一遍完整对局，尤其检查首屏、触屏、音频权限和存档。具体账号/域名/部署步骤取决于你选择的服务，应以其官方说明为准。
